Политика конфиденциальности Volya Analytics

Обновлено: 1 ноября 2026 г.

Volya Analytics — внутренний инструмент владельца проекта «Воля Влиять». Им пользуется только владелец, для своих собственных аккаунтов.

Какие данные приложение получает

  • Статистику собственного YouTube-канала, Instagram- и TikTok-аккаунта владельца: просмотры, удержание, реакции, подписки.
  • Публичные комментарии к роликам канала владельца — чтобы ответить на них от имени канала.

Как данные используются и хранятся

Данные используются только для оценки роликов проекта. Они хранятся локально на компьютере владельца, не передаются третьим лицам, не продаются и не используются для рекламы. Ключи доступа хранятся на этом же компьютере с доступом только для владельца.

Отзыв доступа

Доступ можно отозвать в любой момент: Google — myaccount.google.com/permissions, Meta и TikTok — в настройках приложений аккаунта.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

Volya Analytics is an internal tool used only by the owner of the «Воля Влиять» project for the owner's own accounts. It reads analytics of the owner's YouTube channel, Instagram and TikTok accounts and public comments on the owner's videos in order to reply to them. Data is stored locally on the owner's computer, is not shared with third parties, sold or used for advertising. Access can be revoked at any time in the Google, Meta or TikTok account settings. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: 7140463@gmail.com
